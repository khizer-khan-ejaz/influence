# HiQfluence website

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4 + Framer Motion.

| Route | Content source |
| --- | --- |
| `/` Home | `src/lib/content.ts` |
| `/services` | `src/lib/content.ts` |
| `/insights`, `/insights/[slug]` | Django API (`/api/v1/insights/`), edited in Django admin |
| `/contact` | Form posts to Django API (`/api/v1/inquiries/`) |
| `/privacy`, 404 | Static |

`sitemap.xml`, `robots.txt`, Open Graph image, canonical URLs and JSON-LD (Organization, WebSite, Service, BreadcrumbList, Article) are generated by the app. Retired URLs from the first site version are 308-redirected in `next.config.ts`.

## Local development

```bash
cp .env.example .env.local   # point the API URLs at a running backend
npm ci
npm run dev                  # http://localhost:3000
npm run lint
```

## Environment

| Variable | Purpose | Production |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical origin for metadata and sitemap | `https://hiqfluence.com` |
| `NEXT_PUBLIC_API_URL` | API base used by the browser (contact form) | `/api/v1` (same origin) |
| `API_INTERNAL_URL` | API base used during server rendering | `http://127.0.0.1:8100/api/v1` |

## Contact form

Fields: name, email, company, "What are you working on?". Validated in the browser (zod) and again by the API. Submissions are stored in Django admin under **Inquiries**, and emailed to `INQUIRY_NOTIFICATION_EMAILS` if that is set in the backend `.env`. A hidden honeypot field and a minimum fill time filter out bots.

The API also has industry, objective and budget fields that the form no longer asks for. The form sends neutral values (`other`, `not_sure`, `undecided`) for these. Read the message field for the details.

## Deploying to hiqfluence.com (this server)

The site runs as two systemd services behind the web server: `hiqfluence-frontend` (`next start` on 127.0.0.1:3100) and `hiqfluence-backend` (127.0.0.1:8100). The web server routes `/api/` and `/admin/` to the backend and everything else to the frontend.

```bash
sudo /home/infuence/deploy.sh
```

The script installs dependencies, runs migrations, builds the frontend, restarts both services and checks that they respond.

**One-time step for this release:** move Insights to its three categories and load the revised articles:

```bash
cd /home/infuence/hiqfluence-backend
sudo -u hiqfluence venv/bin/python manage.py restructure_insights --dry-run   # preview
sudo -u hiqfluence venv/bin/python manage.py restructure_insights
```

After deploying, submit the sitemap (`https://hiqfluence.com/sitemap.xml`) in Google Search Console.
